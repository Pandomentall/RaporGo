# RaporGo görsel kimliği

RaporGo’nun işareti, görsel editörde düzenlenen bir rapor sayfasını ve o sayfayı oluşturan
içerik segmentlerini tek biçimde birleştirir. Ürünün ana vaadi editörde rapor hazırlamak,
canlı önizlemek ve PDF almaktır. JSON, CLI ve LLM desteği bu editör deneyimini tamamlayan
isteğe bağlı otomasyon katmanıdır; ana mesajın önüne geçmemelidir.

## Dosyalar

- `logo-mark.svg` — kareye yakın bağımsız işaret
- `logo-lockup.svg` — açık zemin için yatay logo
- `logo-lockup-light.svg` — koyu zemin için yatay logo
- `github-banner.svg` — düzenlenebilir GitHub sosyal önizleme kaynağı (1280 × 640)
- `github-banner.png` — GitHub sosyal önizleme görseli (1280 × 640)
- `readme-banner.svg` — açık zeminli README başlığının düzenlenebilir kaynağı
- `readme-banner.png` — README başlığı (1280 × 360)
- `readme-banner-en.*`, `github-banner-en.*` — aynı iki görselin İngilizce metinli hâli (GitHub README ve sosyal önizleme bunları kullanır)
- `app-icon.svg` — masaüstü uygulama ikonunun düzenlenebilir kaynağı
- `app-icon.png` — masaüstü uygulama ikonu (1024 × 1024)

## Renkler

| Rol | Renk |
|---|---|
| Rapor laciverti | `#1B2A4A` |
| İleri amber | `#F0A500` |
| Arayüz mavisi | `#2E5090` |
| Kâğıt | `#FFFFFF` |

Logonun çevresinde en az işaretin katlanmış köşesi kadar boşluk bırak. İşareti döndürme,
gölge ekleme veya farklı renklerle yeniden kurma. Pazarlama yüzeylerinde rozet, yüzde,
“AI-powered” etiketi ya da parıltı kullanma. Ürün görsellerinde önce editör arayüzünü,
segmentleri ve canlı sayfa önizlemesini göster; JSON/CLI desteğini ikincil mesaj olarak anlat.
